DataJud — Andamentos Processuais Automático · 06h diário
⚖️
API Pública CNJ

O sistema consulta o DataJud diariamente e importa automaticamente as movimentações dos processos ativos, exibindo-as no painel e no Portal do Cliente.

Como funciona
  • Processos ativos são consultados automaticamente pelo número CNJ
  • Movimentações novas são inseridas como andamentos com fonte: datajud
  • Andamentos ficam visíveis no Portal do Cliente automaticamente
  • Deduplicação automática — nenhum andamento é inserido em duplicata

            📖 Como adicionar ao Google Calendar
            
    
                
  1. Abra o Google Calendar → no painel esquerdo, clique em "+" ao lado de "Outros calendários" → "A partir de URL"
    2. 
                
  2. Cole a URL do Feed iCal acima e clique em "Adicionar calendário"
    3. 
                
  3. Pronto! Prazos, audiências e feriados aparecerão automaticamente. O Google atualiza a cada 12–24 h.
    4. 
            

        


        

            📖 Como adicionar ao Outlook
            
    
                
  1. Abra o Outlook → clique em Calendário → "Adicionar calendário" → "Da Internet"
    2. 
                
  2. Cole a URL do Feed iCal e clique em "OK"
    3. 
                
  3. O Outlook sincronizará automaticamente a cada 1–3 h.
    4. 
            

        


        

            📖 Como adicionar ao Apple Calendar (iPhone/Mac)
            
    
                
  1. No Mac: Abra o Calendário → menu Arquivo → Nova Assinatura de Calendário → cole a URL → clique em Assinar
    2. 
                
  2. No iPhone: Configurações → Calendário → Contas → Adicionar conta → Outra → Adicionar Calendário Assinado → cole a URL

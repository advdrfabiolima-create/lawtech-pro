Portal do Cliente — Acesso pelo Site

Acesso Autônomo

Defina um slug para que seus clientes consigam solicitar o link do portal diretamente pelo site do escritório, informando apenas o CPF. O link é enviado para o e-mail cadastrado.

lawtechpro.com.br/acesso/

Use apenas letras minúsculas, números e hífen. Ex: meuescritorio

URL de Acesso dos Clientes

Cole este link no site do escritório ou compartilhe com os clientes. Eles digitam o CPF e recebem o link do portal por e-mail.

Como disponibilizar para seus clientes
  • Via site do escritório: encaminhe a URL gerada acima para o responsável pelo seu site e peça para inserir como um botão ou link — ex: "Acesse seu Portal".
  • Via página de Clientes: acesse o menu Clientes, localize o cliente e clique no botão Portal para gerar e copiar o link individual dele.
  • Direto pelo WhatsApp ou e-mail: copie o link individual do cliente (gerado na página de Clientes) e envie manualmente sempre que precisar.
DataJud — Andamentos Processuais Automático · 06h e 18h
⚖️
API Pública CNJ

O sistema consulta o DataJud duas vezes ao dia (06h e 18h) e importa automaticamente as movimentações dos processos ativos. Para sincronizar um processo individualmente, use o ícone ⟳ na linha do processo na página de Processos.

Como funciona
  • Processos ativos são consultados automaticamente pelo número CNJ
  • Sincronização automática às 06:00 e 18:00 todos os dias
  • Movimentações novas são inseridas como andamentos com fonte: datajud
  • Andamentos ficam visíveis no Portal do Cliente automaticamente
  • Deduplicação automática — nenhum andamento é inserido em duplicata
  • Para sincronizar um processo específico, clique no ícone ⟳ na linha do processo (página Processos)
  • Você também pode inserir andamentos manualmente: na página de Processos, clique no ícone de relógio (⏱) na linha do processo para abrir o modal de Andamentos e registrar uma movimentação diretamente
